ZeitHawk

Craft, replay, and fuzz HTTP requests, then decode, hash, and diff what comes back — a lightweight, browser-only toolkit built in the spirit of Burp Suite's core tools: Repeater, Intruder, Decoder, and Comparer.

⚠ Authorized testing only — only point this at systems you own or are explicitly authorized to test. Every request runs from your browser, so it's bound by the same CORS rules as any web page: the target must allow cross-origin access for you to see its status, headers, or body here, and browsers never let a page override Host, Cookie, Origin, or a handful of other headers. Nothing you enter leaves your browser except the requests you explicitly send.
CORS proxy: on — routes Repeater, Intruder, Recon's DNS/RDAP lookups, and Vuln Scan through a proxy so requests reach targets that would otherwise block cross-origin access. This sends the target URL — and anything you send it (headers, body, payloads) — through whatever endpoint is set below, which you don't control unless you deployed it yourself. Turn this off for anything sensitive, or when testing a target that already sets its own permissive CORS headers.

Default is the public corsproxy.io. See tools/zeithawk/cors-proxy-worker/ in the repo to deploy your own private proxy and paste its URL here instead.

Vuln Scan

A lightweight header/config checker in the spirit of securityheaders.com or Mozilla Observatory — missing security headers, loose CORS, and commonly-exposed sensitive paths (.env, .git/, backup files). Not a signature-based scanner like Nessus/OpenVAS/Nikto, and needs the target to allow cross-origin reads (same CORS limits as Repeater) to see status codes.
